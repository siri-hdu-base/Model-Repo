# 雷达信号分选代码说明

## 工程入口与运行环境

工程位于 Deinterleaving，使用Python、NumPy、SciPy、scikit-learn、h5py、PyTorch、Matplotlib、psutil和pytest。requirements.txt用于跨机器安装；本机实际安装版本另存requirements-lock.txt。Word文档生成依赖与实验环境分开，GPU机器不需要文档工具。

benchmark.py提供inspect、train、evaluate、report和verify-sources五个命令。默认读取configs/smoke.json，配置内相对路径均相对工程根目录解释。输出路径必须位于Deinterleaving，不能通过配置写回论文或TSRD目录。

inspect核验源数和格式；train使用原始train训练三个表征模型、val选择权重；evaluate生成派生样本并评估；report根据已保存逐项结果重新汇总；verify-sources检查保护文件是否变化。

常用命令：

    .\.venv\Scripts\python.exe benchmark.py inspect --config configs/inspect_all.json
    .\.venv\Scripts\python.exe benchmark.py train --config configs/smoke.json
    .\.venv\Scripts\python.exe benchmark.py evaluate --config configs/smoke.json
    .\.venv\Scripts\python.exe benchmark.py evaluate --config configs/scenarios_smoke.json
    .\.venv\Scripts\python.exe benchmark.py report --config configs/smoke.json

正式实验改用configs/full_gpu.json，先train再evaluate。若无CUDA环境，指定GPU的训练会报错，不会静默降级后误报GPU耗时。

## 数据选择与配置字段

subsets接受六个值：scan/train、scan/val、scan/test、stare/train、stare/val、stare/test。all展开为六个独立子集。每个子集映射到其自身目录，分别记录结果。

files可以是文件名列表，也可以是按子集索引的字典；不设置files表示不限文件名。max_files限制排序后的文件数，null表示全部。注意smoke默认只使用config_1.h5，切换all不会清除这一限制。

window_us是观测时长，默认100000；null表示整条记录。windows_per_file为每个文件、每个种子的窗口数量；seeds指定重复种子。time_range_us可限制起点范围。scenarios可填all或显式场景列表。

algorithms可填all或注册名列表。algorithm_params.common作用于所有算法，同名算法字段覆盖common。输出参数会随每条结果保存。timeout_seconds、memory_mb、max_pulses分别限制时间、进程内存和单样本脉冲数；超过限制返回原因，不进行隐式抽样。

profile_dir保存train统计。checkpoint_dir保存模型。training.modes独立控制要训练scan、stare中的哪些模式。训练始终使用对应train和val，不受评估subsets中train/test的选择所误导。

例如只评估scan/test，可运行：

    .\.venv\Scripts\python.exe benchmark.py evaluate --config configs/smoke.json --subsets scan/test --output results/scan_test_only

只评估训练集将scan/test换为scan/train；全部子集换为all。完整六子集评估还要删除files限制，并设置max_files=null。修改代码、配置或权重后必须使用新output目录，防止混合实验。

## 数据模块内部逻辑

data/loader.py定义Sample(x,y,parent,meta)。构造时检查维度、长度与有限数值，转换为float64和int64。take复制所选行，sorted稳定排序PDW并同步标签。feature_order从metadata/feature_names验证列顺序，不猜测未知字段。

files_for解析六子集目录并按config数字排序。load_window以h5py只读模式打开文件，读取时间列确定窗口；有序数据使用连续切片，无序数据使用匹配索引。输出TOA相对窗口起点。文件原索引作为parent，便于还原来源。

fit_train_profile仅访问指定模式train，记录来源清单，生成范围与尺度。pdw_features将圆周角度转换为正余弦；temporal=True时附加DTOA特征。不能在测试数据上重新fit来提高分数。

data/inventory.py核验真实labels中的源数，缓存文件大小/修改时间用于检测源文件变化。统计CSV辅助提供时间范围；其脉冲数量与HDF5不一致时，以HDF5重新检查并记录警告。data/loader.py中的dense_selection只在传入的当前子集记录范围选择≥120源或最大源数并列记录。

data/scenarios.py包含grid、transform、compose。transform始终复制输入，记录原计数、种子、参数及操作结果。pri_intervals提供各PRI规则，scenario_id产生稳定场景标识。compose显式记录组合顺序。

data/snr.py仅提供带SNR标注的外部PDW读取。NPZ需含pdw、labels、snr_db，可含parent。不实现凭幅度推断SNR，也不把低SNR的缺失数据状态伪造为0分。

## 算法模块与统一接口

algorithms/registry.py注册25项。predict(name,x,profile,params,seed)只接收观测及配置；没有测试真值、真实源数或场景名称参数。information返回标题、实现成熟度和主榜/先验分组。strict_papers_only启用时，未通过严格核验的论文项不能评分。

algorithms/classical.py实现六个聚类基线和六个TOA基线。spatial提取RF、PW、圆周AOA；estimated_k由无监督HDBSCAN给出未知簇数估计。candidate_pris实现各TOA候选检测；sequence_chain通过动态规划找允许缺失的近等PRI脉冲链。

algorithms/paper_spatial.py实现EDPC、级联参数、超图、增量leader。共享自然邻居搜索、势熵计算、密度相对距离、预测区间和邻域并簇工具。文中未完全规定的数值补全有配置入口和论文对应表说明。

algorithms/paper_temporal.py实现SAPD的Kalman状态和多假设剪枝、D&S的序列搜索及最大团、先验层次语法的有限状态展开。资源上限不能作为无声截断；超限会返回明确失败原因。语法先验必须提供provenance，不能从当前测试标签构造。

algorithms/neural.py定义GRU、TCN、Transformer表征网络与关系损失，以及NMT、DAE、PCID网络组件。三个基线必须加载已训练权重；缺失时抛RequiredPrior，不能用随机权重评分。checkpoint模式和归一化统计必须与当前评估相符。

论文网络接口要求独立先验。NMT保留原文末脉冲未分类的事实，将其输出为-1；DAE只提取一个已知目标，不把其输出当成未知多源全分选；PCID必须提供逐脉冲对齐的128维真实波形相关特征。

## 训练模块与新增算法

train.py为三个基线逐模式、逐种子训练。WindowChunks只保存来源位置并按需载入数据，最多缓存两个窗口，避免将大规模TSRD全部存入内存。训练按256脉冲分块；只有含至少两源且同时存在同源/异源脉冲对的块参与关系损失训练。

随机种子控制窗口和模型。每轮训练后用对应val计算关系损失，只保存最优轮次。checkpoint记录网络参数、模式、种子、结构、train统计、训练/验证样本位置、参数量、耗时和训练范围。smoke与formal明确区分。

小规模默认每模式6个train和6个val文件，12个训练块、6个验证块、3轮。正式配置默认50轮、三个种子、全部文件10个窗口，并设显式块数上限；实际使用清单是最终依据，不能只看配置名称判断“全量”。

train_paper.py提供有独立先验的论文网络训练入口。配置必须给出kind、prior_provenance、互不相交的train_files/val_files和输出目录。NMT样本NPZ为input[N,1]与target[N]；DAE为input[bins]与target[bins]；PCID为input[5,N]、correlation[128,N]与target[N]。该入口不会自动生成TSRD全局源身份。

新增算法应实现仅依赖观测的预测函数，返回长度N的整数标签。非负值表示预测簇，-1表示拒识。再添加注册信息、可配置参数、人工样例和模块说明。不能把真实标签透传到预测接口，也不能在没有权重时回退到随机模型。

## 评估模块与结果追溯

evaluation/metrics.py用一对一匹配计算源平均F1和准确率，使用稀疏列联计数计算脉冲对指标。父事件等权指标独立命名。拒识真实脉冲仍受惩罚，虚警误吸收进入预测簇精度的分母。空输入和退化划分有明确validity。

evaluation/runner.py将算法放到独立进程，主进程轮询耗时和RSS。超时或内存超限只终止工程创建的推理进程。返回状态包括ok、not_evaluated、timeout、memory_limit、resource_limit、error与worker_crash。预测长度错误也不能当成功。

benchmark.py保存派生样本NPZ、来源JSON、预测NPY与逐项结果JSON。sample_id由配置、来源、种子、窗口和场景确定。每条结果都有算法成熟度、参数、源文件校验值、运行状态和可用指标。

evaluation/report.py生成per_sample.csv、summary.csv、summary.json、场景曲线和结果说明。按原始文件等权平均，不让更多窗口或更多脉冲的文件压倒其他文件。先保存失败记录，再对有效指标汇总，成功覆盖率始终可见。

run目录的config_snapshot.json包含代码、权重、软件版本和profile。断点续跑必须匹配快照；不一致就换output。samples与predictions通过同一sample_id关联，可以重新独立计算任一指标。

默认主指标ARI和源平均F1并列，不强行给出一个综合排名。单文件验证没有有意义的文件级置信区间，留空是正确行为，不能为了表格完整而填入零或虚构误差条。

## 检查方法与已知限制

tests/test_core.py验证六子集、HDF5只读、密集多源筛选、缺失数量、虚警计数、分裂守恒、角度最短弧、调制公式、复现种子、标签置换、全拒识与父事件权重。tests/test_algorithms.py验证注册数量、脉冲链、自然邻居、最大团及基线输出。

测试命令为 .\.venv\Scripts\python.exe -m pytest tests -q。Windows环境对临时目录限制较多时，可显式指定工程内测试临时目录；不要修改原始数据权限来解决测试问题。

verify-sources对所有受保护文件检查大小和修改时间，对论文及实际评估HDF5检查SHA256。检查结果保存在docs/source_verification.json。统计差异写入inventory，原始CSV不修改。

当前论文实现仍有严格复现限制，包括先验缺失、PCID波形输入缺失、部分阈值歧义、网络图连接核验及原论文逐步状态对照。详见docs/论文实现对应表.md。仅以注册项数量或运行成功率宣称全部论文复现完成是不成立的。

小规模结果只能说明程序在所选样本上真实执行及评分。它不能替代全体数据、多种子、充分训练和论文原场景核验。正式GPU配置是后续运行入口，不表示正式实验已经运行。

短观测可能无脉冲，密集多源回退可能少于120源，TOA有限精度来自原始数据。上述事实必须随结果保留。低SNR无数据时的未评估状态也属于预期输出。
